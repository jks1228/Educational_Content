## 2. 항목별로 본 공통점

1. **진단 → 추천 흐름:** 공공(EBS AI, 강남인강)과 콴다는 "진단 → 약한 곳 → 강좌/문제 추천"이고, 상업 인강은 "학년 → 과목 → 선생님 비교"가 중심. 진단 결과를 **설명하는 리포트**(오답 원인, 시간)를 주는 곳(콴다일로, 진학사)이 신뢰를 얻음.
2. **첫 화면:** 거의 모두 **학년을 먼저** 정함(메가스터디 왼쪽 위, EBSi 상단, 강남인강 3칸 선택). 우리 서비스의 1단계(학년·과목)와 같은 방향.
3. **과목·단원 찾기:** EBSi "교과서 단원별"(출판사 → 대단원 → 중단원 → 소단원)이 가장 촘촘. 우리 데이터는 대단원까지(중단원은 단계 A3).
4. **강의 카드:** 공통 정보 = 강좌명, 강사, **강 수·총 시간**, 학습단계·난이도, 대상, 후기. 우리 카드에는 강사(EBSi), 길이/강 수, 추천 이유, 확인한 날이 있고 **난이도·학습단계는 없음**.
5. **PC 레이아웃:** 모두 PC에서 넓은 화면을 씀. 상단 메뉴(학년·과목), 본문은 목록/카드 그리드 + 옆 보조 영역(랭킹·알림·선택 요약). 휴대폰 폭 한 줄만 보이는 사이트는 없음 → 3단계(PC 레이아웃)에서 반영.
6. **무료/유료:** 상업 사이트는 "맛보기·OT·무료강좌"로 무료를 따로 표시. 우리는 **무료만** 추천하므로 "무료"를 카드마다 표시하고, EBSi처럼 **로그인이 필요한 곳은 따로 안내**하는 것이 맞음.
