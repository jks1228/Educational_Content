## 1. 화면 흐름

```
S0 시작 ──▶ S1 기본 정보 ──▶ S2 성적 ──▶ S3 영역 체크 ──▶ S4 진단 결과 ──▶ S5 추천
 (고지)      학년·과목·목적     과목별       과목 탭마다        과목별 수준       과목 탭마다
                                 입력        3단계 체크         우선 영역         영역별 강의·책
```

| ID | 화면 | 하는 일 | 다음으로 가는 조건 | 뒤로 |
|----|------|---------|--------------------|------|
| S0 | 시작 = **랜딩페이지** | 서비스 설명, 3단계 흐름, 결과 예시, 개인정보 고지, 진단 시작 (`landing.html`) | "진단 시작하기" | — |
| S1 | 기본 정보 | 학년(중1~고3) 1개, 과목(국·영·수) 1개 이상, 고등학생은 학습 목적 | 학년·과목 선택, 고등학생은 목적까지 | S0 |
| S2 | 성적 | 과목마다 성적 입력. 중학생: 점수 또는 성취도. 고등학생: 내신·모의고사 중 하나 이상 | 과목마다 성적 1개 이상, 범위 오류 없음 | S1 |
| S3 | 영역 체크 | 과목 탭마다 영역별 자신 있음/보통/약함 | 모든 영역 체크 (기본값 없음, 빠진 영역 안내) | S2 |
| S4 | 진단 결과 | 과목별 수준(상/중/하)과 그 근거, 약함 → 보통 순서의 우선 영역 | "추천 보기" | S3 |
| S5 | 추천 | 과목 탭마다 영역별 추천 방향, 강의 1~2, 책 1~2, 준비 중 안내, 숨기기(P1), 인쇄(P1), 만족도 | — | S4 |

- **랜딩페이지와 S0의 관계: 랜딩이 S0을 대체합니다.** S0에 있던 제목·설명·개인정보 고지·광고 없음 안내·지원 범위를 랜딩이 모두 담고, "진단 시작하기"를 누르면 바로 S1로 갑니다. 학생이 같은 소개를 두 번 보지 않게 하기 위해서입니다. `index.html`의 S0 화면은 진단 화면 묶음 안에서 참고용으로 남겨 둡니다.
- 화면 위에 단계 표시(1/5 ~ 5/5)를 둡니다. S0은 단계에 넣지 않습니다. 실제로 순서가 있는 흐름이라 숫자를 씁니다.
- "뒤로"를 눌러도 입력값은 유지합니다. 새로고침하면 처음부터입니다 (저장하지 않음, PRD 6장).
- 과목이 여러 개면 S3와 S5 모두 **같은 과목 탭**으로 나눕니다 (사용자 결정, 아래 "결정된 사항"). S3에서는 체크를 마친 과목 탭에 완료 표시를 합니다. S4는 과목이 많지 않아(최대 3개) 한 화면에 이어서 보여 줍니다.
- **입력 범위 오류 (PRD F-1.6 해석):** PRD는 "범위를 벗어난 값은 입력할 수 없고"라고 적었습니다. 설계에서는 값을 칠 수는 있게 두고, 바로 오류 문장을 보여 주며 고치기 전에는 "다음"을 막습니다. 무엇이 틀렸는지 보여 주는 편이 학생에게 더 알기 쉽기 때문입니다. 범위 밖 값으로는 진단이 진행되지 않는다는 점은 같습니다.

## 3. 디자인 기준
frontend-design skill의 두 단계 방식(계획 → 기본값과 비교해 수정 → 제작)으로 정했습니다.

### 방향: 국내 입시 포털형 (사용자 요청 2026-11-09, 사용자 확인 2026-11-10: 대체로 승인, 세부 조정 가능)
국내 입시·인강 포털의 **전반적인 느낌**을 참고합니다. 진한 코발트 단색 띠, 아주 굵은 한글 제목, 정보가 촘촘한 흰 카드, 고른 버튼을 진한 남색으로 채우는 방식입니다. 다만 이 서비스는 강의를 파는 곳이 아니라서, **판매·홍보처럼 보이는 요소는 모두 뺐습니다** (PRD R-7).
이전 방향(모눈 노트 + 형광펜, 사용자 승인)은 이번 요청으로 바뀌었습니다. 비교용으로 `design/mockups/previous/notebook.html`과 `design/screenshots/previous/`에 남겨 두었습니다.

**참고한 요소와 일부러 피한 요소** (사용자가 예로 든 국내 입시 포털의 첫 화면을 2026-11-09에 직접 보고 정리. 참고 캡처는 저장소에 넣지 않았고, 2026-11-10에 지움)

| 참고한 것 (느낌만) | 이 서비스에서 바꾼 방식 |
|--------------------|------------------------|
| 진한 파랑 계열의 큰 색 면 | 고유한 코발트 `#2347C6`을 화면 위 띠에만 씀. 그라데이션 없이 단색 |
| 아주 굵은 한글 제목 | Gothic A1 900 굵기 |
| 고른 메뉴를 진한 바탕 버튼으로 표시 | 고른 칩·탭(학년, 과목, 학습 목적, 과목 탭)을 남색 `#16204A`으로 채우고 ✓ 붙임. 단, S3 영역 체크의 "자신 있음"은 연하게 (아래 색 절) |
| 과목별 바로가기 칩 | S1 과목 타일(국·영·수), S3·S5 과목 탭 |
| 흰 카드 + 얇은 회색 테두리, 정보 밀도 | 카드에 정보를 촘촘히 넣되 그림자 없이 테두리만 |

| 일부러 피한 것 | 이유 |
|----------------|------|
| 참고 사이트의 이름·로고·상품명·문구, 고유 배치(왼쪽 세로 메뉴 + 큰 홍보 카드 + 인기 목록) | 상표·고유 디자인 복제 금지. 서비스 이름은 `〈서비스 이름〉` 자리 표시 |
| 강사·모델 사진, 일러스트 | 복제 금지, 홍보 느낌 |
| "마지막 기회", 판매 종료일, "HOT" 같은 배지·마감 표현 | 광고처럼 보임 (R-7) |
| 마젠타·형광 연두 홍보 카드, 그라데이션 배너 | 광고처럼 보임 |
| 채팅 상담 버튼, 떠 있는 홍보 배너 | 이 서비스에 필요 없음 |

**광고처럼 보이지 않게 넣은 것:** S0·S5에 "추천에는 제휴·광고 링크가 없어요" 안내, "무료" 표시는 반짝이는 배지가 아니라 차분한 정보 칩, 외부 링크는 "새 탭에서 보기"처럼 하는 일을 그대로 적음.

| 처음 계획 | 기본값과 비교해 바꾼 점 |
|-----------|------------------------|
| 파란 띠에 그라데이션 + 큰 숫자 강조 | 생성형 디자인에 흔한 조합이라 단색 띠 + 굵은 문장 제목으로 |
| 모든 것을 똑같이 둥근 카드 + 그림자로 | 흔한 카드 모음이라 그림자를 빼고, 둥글기를 위계별로 다르게 (화면 18px, 카드 14px, 버튼 10px, 표시 6px) |
| 강조색 여러 개 | 노랑("약함") 하나만 강조로 남김. 코발트는 면, 남색은 고른 상태 |
