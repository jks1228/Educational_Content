# 📚 학습 진단 후 강의·책 추천

> 중·고등학생이 자기 성적과 약한 부분을 직접 체크하면, 그 결과에 맞는 강의와 책을 추천해 주는 교육 콘텐츠입니다.

> ⚠️ **현재 상태:** 기획 단계입니다. 아래의 진단 문항, 추천 목록, 폴더 구조는 앞으로 만들 내용의 설계안이며 아직 실제 파일은 없습니다.

## 소개
많은 학생이 "무엇을 공부해야 할지"보다 "어디서부터 시작해야 할지"를 더 어려워합니다.
이 콘텐츠는 학생이 **현재 성적**과 **약하다고 느끼는 단원·영역**을 스스로 체크하면,
그 결과에 맞춰 **수준에 맞는 강의**와 **보충할 책**을 골라 줍니다.

## 대상 학습자
| 구분 | 학년 | 비고 |
|------|------|------|
| 중학생 | 중1 ~ 중3 | 교과 기본 개념 보충 중심 |
| 고등학생 | 고1 ~ 고3 | 내신·수능 대비 심화 포함 |

- **사전 지식:** 없음 (자기 성적과 학년만 알면 됩니다)
- **진단 소요 시간:** 약 5~10분 (목표)

## 학습 목표
이 콘텐츠를 이용하면 학생은 다음을 할 수 있습니다.
1. 과목별로 자기 수준과 약한 영역을 스스로 점검합니다.
2. 약한 영역부터 우선순위를 정해 공부 계획을 세웁니다.
3. 자기 수준에 맞는 강의와 책으로 효율적으로 보충합니다.

## 이용 흐름
```
① 기본 정보 입력      학년, 진단할 과목 선택
                      (고등학생) 학습 목적: 내신 대비 / 수능 대비 / 둘 다
        ↓
② 성적 체크           최근 시험 점수나 등급 입력 (고등학생은 내신·모의고사 둘 다 가능)
        ↓
③ 약한 부분 체크      단원·영역별로 "자신 있음 / 보통 / 약함" 선택
        ↓
④ 진단 결과           과목별 수준 + 우선 보충할 영역 정리
        ↓
⑤ 맞춤 추천           영역별 추천 강의 + 추천 책 목록
```

## 진단 항목
### 1. 성적 체크
- **중학생:** 최근 시험 점수(100점 만점) 또는 성취도(A~E)
  - 체육·예술 과목은 성취도가 A~C 3단계입니다.
- **고등학생:** 내신 등급과 모의고사 등급(1~9등급) 중 하나 또는 둘 다
  - 내신은 학년마다 등급제가 다릅니다. 2026학년도 기준 **고1·고2는 5등급제**, **고3은 9등급제**입니다. (2025학년도 고1부터 5등급제 적용)
  - 모의고사와 수능은 학년과 관계없이 9등급제입니다.

### 2. 약한 부분 체크 (예시)
| 과목 | 체크 영역 예시 |
|------|----------------|
| 국어 (중1·중2, 2022 개정) | 듣기·말하기, 읽기, 쓰기, 문법, 문학, 매체 |
| 국어 (중3, 2015 개정) | 듣기·말하기, 읽기, 쓰기, 문법, 문학 |
| 국어 (고1, 2022 개정 공통국어1·2) | 듣기·말하기, 읽기, 쓰기, 문법, 문학, 매체 |
| 국어 (고2, 2022 개정 선택과목) | 문학, 독서와 작문, 화법과 언어 |
| 국어 (고3, 2015 개정 선택과목) | 문학, 독서, 화법과 작문, 언어와 매체 |
| 영어 | 어휘, 문법, 독해, 듣기 |
| 수학 | 학년별 단원 (예: 중2 일차함수, 고1 다항식) |
| 사회·과학 | 학년별 단원 |

- 학년별 교육과정은 2026학년도 기준입니다. 고등학교 선택과목은 학교마다 배우는 학년이 다를 수 있으니, 지금 배우는 과목 기준으로 체크합니다.

각 영역은 **자신 있음 / 보통 / 약함** 세 단계로 체크합니다.

## 추천 기준
추천은 **성적 수준**과 **영역별 체크 결과**를 함께 보고 정합니다.

### 1. 성적 수준 정하기
입력한 성적을 아래 표에 따라 상·중·하로 나눕니다.

> 📝 아래 경계값은 **임시 기준**입니다. 실제 콘텐츠를 만들면서 조정할 수 있습니다.

| 수준 | 중학교 점수 | 중학교 성취도 | 내신 9등급제 | 내신 5등급제 | 모의고사 |
|------|-------------|---------------|--------------|--------------|----------|
| 상 | 90점 이상 | A | 1~2등급 | 1등급 | 1~2등급 |
| 중 | 70~89점 | B~C | 3~5등급 | 2~3등급 | 3~5등급 |
| 하 | 69점 이하 | D~E | 6~9등급 | 4~5등급 | 6~9등급 |

- 체육·예술(A~C) 과목은 A = 상, B = 중, C = 하로 봅니다.
- 고등학생이 내신과 모의고사를 둘 다 입력하면, ① 기본 정보에서 고른 학습 목적에 따라 기준을 정합니다.
  - **내신 대비** → 내신 등급 기준
  - **수능 대비** → 모의고사 등급 기준
  - **둘 다** → 두 등급 중 **낮은 쪽 수준** 기준 (약한 쪽을 먼저 보충하기 위해서입니다)
- 한 가지 성적만 입력했다면 학습 목적과 관계없이 그 성적을 기준으로 합니다.

### 2. 추천 방향 고르기
| 성적 수준 | 영역 체크 | 추천 방향 |
|-----------|-----------|-----------|
| 하 | 약함 | 개념 기초 강의 + 쉬운 개념서 |
| 하 | 보통 | 개념 기초 강의 + 기본 문제집 |
| 중 | 약함 | 개념 정리 강의 + 유형별 문제집 |
| 중 | 보통 | 유형 연습 강의 + 기본 문제집 |
| 상 | 약함 | 개념 정리 강의 + 고난도 문제집 |
| 상 | 보통 | 심화 강의 + 고난도 문제집 |

- **"자신 있음"으로 체크한 영역은 추천하지 않습니다.** 약한 영역에 시간을 쓰도록 하기 위해서입니다.
- 다만, 한 과목의 모든 영역이 "자신 있음"이면, 그 과목은 **자기 성적 수준의 "보통" 칸** 추천을 참고합니다.
- 한 영역마다 **강의 1~2개, 책 1~2권**을 추천해서 선택 부담을 줄입니다.
- 추천 목록에는 **제목, 대상 학년, 난이도, 추천 이유**를 함께 적습니다.
- 강의는 무료로 볼 수 있는 공공 강의(예: EBS)를 먼저 추천합니다.

## 폴더 구조 (제안)
> 아직 만들지 않은 구조입니다. 콘텐츠를 추가할 때 이 구조를 따릅니다.

```
.
├── diagnosis/            # 진단 문항
│   ├── middle/           # 중학교 과목별 체크리스트
│   └── high/             # 고등학교 과목별 체크리스트
├── recommendations/      # 추천 목록
│   ├── lectures/         # 과목·영역·난이도별 강의 목록
│   └── books/            # 과목·영역·난이도별 책 목록
├── guides/               # 진단 결과 읽는 법, 공부 계획 세우기 안내
├── assets/               # 이미지, 도표 등 공용 리소스
└── README.md
```

## 사용 방법
> 위 [폴더 구조](#폴더-구조-제안)가 만들어진 뒤의 사용 방법입니다.

### 학생
1. `diagnosis/`에서 자기 학년(중학교/고등학교) 폴더를 엽니다.
2. 과목별 체크리스트에 성적과 약한 부분을 체크합니다.
3. [추천 기준](#추천-기준)에서 내 성적 수준을 정하고, 영역별 추천 방향을 확인합니다.
4. `recommendations/`에서 해당 영역의 강의와 책을 골라 공부를 시작합니다.

### 교사·학부모
- 학생과 함께 진단 결과를 보며 공부 우선순위를 정하는 상담 자료로 쓸 수 있습니다.
- 추천 목록은 학생 상황에 맞게 더하거나 뺄 수 있습니다.

## 콘텐츠 작성 가이드
- **진단 문항:** 교육과정 단원명을 그대로 쓰고, 학생이 이해하기 쉬운 말로 풀어 씁니다. 어느 교육과정(2015 개정 / 2022 개정) 기준인지 함께 적습니다.
- **추천 항목:** 제목, 출판사·제공처, 대상 학년, 난이도(하/중/상), 추천 이유를 꼭 적습니다.
- **최신성:** 개정 교육과정과 절판 여부를 확인하고, 마지막 확인 날짜를 적습니다.
- **광고 배제:** 특정 업체 홍보가 아닌, 학습 효과를 기준으로 추천합니다.
- **파일 이름:** `<학년코드>-<과목 영문>-<영역 영문>.md` 형식을 따릅니다.
  - 학년코드: `m1`~`m3`(중1~중3), `h1`~`h3`(고1~고3)
  - 예: `m2-math-linear-function.md`, `h1-english-reading.md`

## 개인정보 안내
- 진단에는 이름, 학교 등 개인을 알아볼 수 있는 정보를 받지 않습니다.
- 성적 정보는 추천에만 쓰고 따로 저장하지 않는 것을 원칙으로 합니다.
- 나중에 웹이나 온라인 폼으로 정보를 받게 되면 별도로 검토합니다. 중1~중2에는 만 14세 미만 학생이 포함되어 법정대리인 동의가 필요할 수 있습니다.
